## ✨ Overview

Built as a high-impact personal portfolio, this app showcases a modern development brand with immersive interactions and polished UI.

It is designed to feel like a live system console where visitors can explore projects, skills, experience, and contact workflow through a unique cybernetic interface.

## 📌 Key Highlights

- **Immersive UI**: Glassmorphism, animated layouts, and dark cyberpunk styling
- **Terminal-driven navigation**: Real-time command palette for `help`, `about`, `projects`, `skills`, `experience`, and more
- **Dynamic showcase**: Project cards, skill groups, timeline entries, and resume modal
- **Secure presentation**: Contact form feels like an encrypted collaboration gateway
- **React + TypeScript + Vite**: Fast development, modern tooling, and strong type safety

## 🎯 What’s Included

| Section      | What it does                                                                   |
| ------------ | ------------------------------------------------------------------------------ |
| `Profile`    | Displays developer bio, location, contact links, and resume access             |
| `Projects`   | Shows featured repository with tags, description, and demo links               |
| `Skills`     | Organized technology matrix across frontend, backend, algorithms and languages |
| `Experience` | Timeline layout for internship experience and technical achievements           |
| `Terminal`   | Command-style interface for interactive portfolio exploration                  |
| `Contact`    | Secure-style message form with drag/drop file support                          |


## 🧩 Run Locally

### Requirements

- Node.js installed

### Start the app

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## 📦 Build for Production

```bash
npm run build
```

## 🗂️ Project Structure

- `src/App.tsx` — main app logic with pipeline and data loaders
- `src/data.ts` — portfolio content, projects, skills, experience, and owner metadata
- `src/components/ContactForm.tsx` — interactive contact gateway and upload UX
- `src/components/TerminalWidget.tsx` — command-driven terminal experience
- `src/components/ResumeModal.tsx` — resume modal and download flow
- `src/utils/sheetFetcher.ts` — optional dynamic spreadsheet loader

## 🔧 Notes

- The contact form is styled as a secure gateway and can optionally send data via a webhook if configured.
- The app is built to highlight both frontend polish and developer storytelling.
